<h2>一、客户端选型建议</h2>
        <ul>
          <li><strong>Clash Meta for Android（推荐）：</strong>适合绝大多数用户，界面美观、分流规则强大，完美支持 Shadowsocks、VLESS、Trojan 等全协议。</li>
          <li><strong>v2rayNG（轻量备选）：</strong>架构轻量，内存占用极低，适合配置较低的老旧安卓机型。</li>
        </ul>

        <h2>二、Clash Meta 配置操作步骤</h2>
        <ol>
          <li><strong>下载安装包：</strong>从 GitHub 开源发布页或正规应用镜像下载 APK 并安装。</li>
          <li><strong>导入配置：</strong>打开应用，点击“配置（Profiles）”→ 点击右上角“+”号 → 选择“从 URL 导入” → 粘贴从机场后台复制的 Clash 订阅链接 → 点击右上角保存。</li>
          <li><strong>启动连接：</strong>返回主界面，点击中间灰色“点击启动”按钮（首次运行系统会弹出 VPN 权限确认提示，点击“允许”即可）。</li>
          <li><strong>分流模式设置：</strong>进入“代理”页面，确保顶部模式为“规则（Rule）”，选择延迟最低的绿色节点开始使用。</li>
        </ol>

        <h2>三、安卓系统省电策略设置（重要）</h2>
        <p>很多安卓用户反馈梯子切到后台几分钟后就自动断连，这是因为国产手机系统（MIUI/HyperOS、OriginOS、ColorOS等）默认的激进电池管理杀掉了后台进程。<strong>请务必在“应用信息”中将 Clash 设置为“无限制自启动”与“允许后台高耗电运行”。</strong></p>
