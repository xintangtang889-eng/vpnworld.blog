Windows 客户端配置与机场节点使用教程

更新时间：2026年3月 · 推荐主力客户端：Clash Verge Rev（开源免费、支持Mihomo内核、内置中文）

一、为什么强烈推荐 Clash Verge Rev？

在原 Clash for Windows 停更之后，社区基于最新 Mihomo（Clash.Meta）内核开发了 Clash Verge Rev。它具备原生支持 Windows 11/10 现代 UI、内置中文界面、支持一键开启 Tun 虚拟网卡代理以及强大的分流规则热更新能力，是目前 Windows 平台翻墙的首选。

二、图文四步配置流程

  1. 步骤 1：下载安装客户端。 从官方开源 GitHub Releases 下载 Clash.Verge_x64-setup.exe 并运行安装。
  2. 步骤 2：获取并导入机场订阅。 登录您的机场后台（如 微风网络 或 隐形人），点击“复制 Clash 订阅链接”。在 Clash Verge Rev 中点击左侧菜单“订阅（Profiles）”，将链接粘贴在顶部输入框并点击“导入（Import）”。
  3. 步骤 3：选择模式与节点。 点击左侧“代理（Proxies）”，将模式选择为 规则（Rule） 模式（避免全局代理消耗不必要的国内流量）。在节点分组中展开并勾选您想使用的落地地区（如香港、日本、新加坡或美国）。
  4. 步骤 4：开启系统代理或 Tun 模式。 点击左侧“设置（Settings）”，打开 系统代理（System Proxy） 开关。如果需要让不支持系统代理的软件（如 Git、特定游戏、CMD命令行）也能代理，建议开启 Tun 模式。

三、常见问题与避坑提示

提示：如果开启代理后提示“无法连接代理服务器”或所有节点 Ping 超时，请优先排查 Windows 系统时间是否与北京时间准确同步（时间偏差超过60秒会导致握手加密失败）。详细排查请阅读：机场节点全部超时不可用？10个排查方法。
