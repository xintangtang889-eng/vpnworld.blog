Docker 部署代理服务实操指南：让整个容器网络丝滑加速

作者：VPNWorld 资深评测团队 更新时间：2026-03-01 分类：Linux / Docker 预计阅读：11 分钟
核心导读：在 Linux 服务器集群或家用群晖 NAS 上，如果每个容器单独配置代理极其低效繁琐。通过运行一个独立的轻量 Sing-box 代理容器，并配置 host 或 macvlan 网络，可以让所有容器环境共享高速境外网络。本文手把手演示实战部署。

一、编写极简 docker-compose.yml

undefined

version: '3'
services:
  sing-box:
    image: ghcr.io/sagernet/sing-box:latest
    container_name: sing-box
    restart: always
    network_mode: host
    volumes:
      - ./config.json:/etc/sing-box/config.json
    cap_add:
      - NET_ADMIN

二、配置容器镜像拉取与环境变量分流

利用上述容器提供的本地 7890 端口，可让 Docker Daemon 守护进程无缝拉取境外镜像，彻底解决国内服务器拉取 Docker Hub 频繁连接超时的问题。
