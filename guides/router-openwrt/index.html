OpenWrt 软路由全局翻墙实操：全屋设备无感透明代理

作者：VPNWorld 资深评测团队 更新时间：2026-03-01 分类：OpenWrt 软路由 预计阅读：16 分钟
核心导读：通过在软路由（如工控机 J4125、N5105、R2S/R4S 或老旧电脑）上部署 OpenWrt，可以实现全家局域网内所有手机、电脑、智能电视（Apple TV / 索尼电视）以及主机游戏机（PS5/Switch）开机即自带科学上网，彻底摆脱每台设备单装客户端的繁琐。

一、主路由 vs 旁路由模式选型

如果家里网络结构简单，推荐将 OpenWrt 设为唯一主路由（PPPoE 拨号）；如果已有硬路由（如华硕、小米路由器）提供 Wi-Fi，建议采用‘旁路由（网关模式）’，只需将需要翻墙的设备网关与 DNS 指向软路由 IP 即可，主网络稳定性不受任何干扰。

二、OpenClash 核心配置与 Fake-IP 模式

undefined

  1. 在 OpenWrt 后台进入【服务】->【OpenClash】->【配置文件订阅】，添加机场订阅链接。
  2. 在【插件设置】中将运行模式切换为【Fake-IP（增强模式）】，内核选择【Meta 核心】。
  3. 开启【绕过中国大陆 IP】与【大陆白名单】，确保国内流量跑在千兆硬转发上不消耗软路由 CPU 性能。
