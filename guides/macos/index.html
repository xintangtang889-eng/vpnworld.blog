macOS 苹果电脑客户端翻墙教程与配置指南

更新时间：2026年3月 · 全面兼容 Apple Silicon (M1/M2/M3/M4) 及 macOS Sequoia / Sonoma 系统

一、推荐客户端选型

  • Clash Verge Rev（免费开源推荐）：全功能适配 Mac 原生深浅色主题，支持 Tun 虚拟网卡模式，一键接管全部终端与应用网络。
  • Surge Mac（高端专业付费）：Mac 平台上最强大的网络调试与规则分流神器，适合开发者与对网络监测有极致要求的极客。

二、Clash Verge Rev Mac 版安装指引

  1. 选择对应芯片版本：如果是苹果 M 系列芯片（M1~M4），请下载包含 aarch64.dmg 的安装包；如果是旧款 Intel 芯片，请下载 x64.dmg。
  2. 初次打开权限处理：将图标拖入“应用程序”后，如果系统提示“无法打开，因为无法验证开发者”，请进入 Mac 的 系统设置 → 隐私与安全性，在底部点击“仍要打开”。
  3. 导入订阅并开启 Tun 模式：粘贴机场订阅后，建议在“设置”中安装 Service 服务模式，并开启 Tun Mode，让 Mac 的 Terminal 终端与 Docker 容器也能无感走代理。
